    How each total is built

    Theory course
    Mid Exam × 25% + Class Test × 10% + Quiz/Presentation (direct) + Final Exam × 50%
    1‑credit lab course
    Class Participation (direct) + Viva × 20% + Lab Test × 20% + Lab Report × 50%
